**Certifications:** AZ-700, AZ-500, SC-500, SC-100, SC-200, AI-102, AWS Security Specialty, Terraform Associate, CEH, ISO 27001 Lead Implementer, TOGAF 9

## Network and firewall

- [fwmigrate](https://github.com/falshaw/fwmigrate): firewall rule-base migration between vendors: parse, find shadowed and over-permissive rules, translate, review, export.
- [netmap](https://github.com/falshaw/netmap): network discovery and topology mapping (SNMP, nmap, ARP) with draw.io export.
- [firewall-agents](https://github.com/falshaw/firewall-agents): vendor expert personas, migration playbooks and study notes for firewall engineers using Claude Code.

## Secure, private AI

- [secure-private-ai](https://github.com/falshaw/secure-private-ai): authenticated LLM gateway with allowlist and rate limits, local models for bulk text, shared JWT auth.

- [complibot](https://github.com/falshaw/complibot): drafts answers to vendor security questionnaires from your own knowledge base on a local LLM, with human review before export.
