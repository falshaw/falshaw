Network and firewall security engineer. Palo Alto first, plus Cisco, Fortinet and F5. I plan and run firewall migrations and change programmes for large enterprises, and I build secure, local-first AI tooling around that work.

**Certifications:** AZ-700, AZ-500, SC-100, SC-200, AI-102, Terraform Associate, CEH, ISO 27001 Lead Implementer, TOGAF 9

## Network and firewall

- [fwmigrate](https://github.com/falshaw/fwmigrate): AI-assisted firewall migration. Parse, translate and review rulebases across vendors.
- [netlab](https://github.com/falshaw/netlab): routing lab in GitHub Codespaces. FRRouting for OSPF, BGP and MPLS, plus cheat sheets.
- [netmap](https://github.com/falshaw/netmap): network discovery and mapping with AI-assisted analysis.

## Secure, private AI

- [secure-private-ai](https://github.com/falshaw/secure-private-ai): authenticated LLM gateway with allowlist and rate limits, local models for bulk text, shared JWT auth.
- [vaultic](https://github.com/falshaw/vaultic): fully local AI assistant with RAG, PII redaction at ingest and no data leaving the host.
- [complibot](https://github.com/falshaw/complibot): answers vendor security questionnaires from your own knowledge base.
